# GitHub Trending article pipeline

The pipeline uses GitHub's daily, weekly, and monthly Trending views rather than reconstructing historical calendar periods, because the project has no prior snapshots to recover those rankings. Oban schedules collection and ReqLLM from the Jido ecosystem drafts one Chinese article from due rankings. Provider/model/key/endpoint are runtime-configurable; an OpenAI-compatible OpenCode Go endpoint can be selected through its dedicated environment variables without coupling this app to the adjacent `ai-agents` project's unrelated decision adapters. The Markdown file remains the source of truth, a content-only local Git commit records it, and the workflow creates or updates a WeChat draft for human review and publication. This favors auditable editorial content over direct publication while keeping the model provider configurable.
